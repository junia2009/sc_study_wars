# SC STUDY WARS 〜障害報告書は書きたくない〜

情シス見習いのあなたが、相棒 AI「ガード」と一緒に、経理部を詐欺から1週間守り抜くドット絵の横スクロールアクション。
高校生以上・社会人向け。詐欺を「当てる」のではなく、「確かめる習慣」を身につけるのがねらい。

**▶ https://junia2009.github.io/sc_study_wars/**

企画書(第2版): https://claude.ai/artifact/9U7wc2Vn2T5Y1f3K3Q6wmq

## 遊び方

名前はタイトル画面で入力する。初めて遊ぶときは、まずオープニングムービー(約50秒・スキップ可)が流れる。
ゲームと同じドット絵をゲームの画面で動かしていて、舞台・黒幕・3つの基本動作・ガードを紹介する(タイトルからもう一度見られる)。

月曜の最初には練習区間があり、ガードが1つずつ教える(移動・ジャンプ・業務データ・敵・「!」ブロック・穴・画面の見方)。
練習区間では、ぶつかっても落ちてもゲージは増えない。判断シーンと結果画面は、初めて見たときにガードが画面の各部分を光らせて説明する。
一度その日を最後まで遊ぶと、2回目からは遊び方の説明は出ず、物語の会話だけになる(台本で `help: true` の説明)。

1日(1ステージ)はこう進む。

1. **朝**: 情シスの黒田先輩から依頼を受け、3つの基本動作を教わる(①見る ②別の道で確かめる ③迷ったら相談・やったら報告)
2. **ネットワーク(アクション)**: ガードを操作して、判断で使う「手がかり」を集める(公式ブックマーク・連絡先台帳)
   - **メール便の仕分け**(試作): 本物と偽物のメール便が同じ姿で歩いてくる。頭の上の札(差出人のドメイン)を読んで、
     偽物(`sanple-bussan` などの1文字違い)は踏んで撃退、本物は受け止めて届ける。どれが偽物かは毎回変わる。
     本物を踏む・受け取りそこねると業務の遅れ、偽物を受け取る・素通りさせると漏洩リスクがたまる
3. **判断シーン**: 経理の佐藤さんからの相談や、自分あてのメールが届く。まずメールの怪しいところ(差出人のドメイン・返信先・口座・急かす言い回しなど)を
   タップして印を付け、それから4つの選択肢から対応を選ぶ。手がかりを持っていると「確かめる」選択肢が開く。選択肢の並びは毎回変わる
4. **結果**: 最善・安全だが遅い・惜しい・引っかかった、の4段階。答え合わせでは、印を付けたところが
   見抜いた(緑)・見落とし(黄)・疑いすぎ(紫)に色分けされる。見抜くと評価が上がり、疑いすぎると業務の遅れがたまる。
   本物のメールなら、印を付けないのが正解
5. **夕方**: 黒幕「アングラー」が明日の手口を予告し、先輩との振り返りで評価(S〜D)と解説カードをもらう

ゲージは2本。詐欺に引っかかると「漏洩リスク」が、本物を疑いすぎたり何でも先輩に任せたりすると「業務の遅れ」がたまる。
光る結晶は「業務データ」で、拾うと業務の遅れが少し減る。3つの基本動作・ゲージ・評価の決まり方は、手帳の「きほん」でいつでも見返せる。
漏洩リスクが満タンなら障害報告書、業務の遅れが満タンなら始末書(どちらもゲームオーバー)。

| 操作 | PC | スマホ(縦でも横でも) |
| --- | --- | --- |
| 移動 | ← → / A D | 左右のキー。間を指で滑らせると切り替わる |
| ジャンプ(押す長さで高さが変わる) | Z / スペース | A |
| 手帳(集めた手がかりを見る) | X / ↑ | B |
| 会話を送る | Enter / スペース / Z | タップ |
| 判断シーンの選択 | 数字キー 1〜4 | タップ |
| 一時停止 | Esc / P | 右上の ⏸ |

ゲームパッドでも動く(A でジャンプ、B か X で手帳)。

スマホのコントローラーは、見た目と押せる範囲を一致させている(ボタンのまわり 14px だけ、指のずれを許す)。
左右のキーの間を滑らせると向きが切り替わり、ボタンから大きく指を離すと押していないことになる。
縦向きは、上がゲーム画面・下が薄いコントローラーの台。見える横幅を 10〜13 マスに絞ってキャラを大きく映し、
余った高さは床の上の景色として映す。横向きは、画面の形に合わせて見える横幅を広げ、ボタンを半透明で重ねる。

## 今あるもの

**月曜**(社内ポータル → 経理部のファイルサーバー → ログアウトゲート)まで。火曜以降は準備中。

| 時刻 | 判断シーン | 最善の答え | 使う手がかり |
| --- | --- | --- | --- |
| 10:30 | 取引先からの本物の請求書(佐藤さんの相談) | 台帳と見比べてから処理する(疑いすぎると業務が遅れる) | 連絡先台帳 |
| 14:00 | 取引先を名乗る「至急」の振込先変更(佐藤さんの相談) | 台帳の番号で本人に電話して確かめる | 連絡先台帳 |
| 16:30 | パスワード期限切れを装うフィッシング(自分あて) | リンクは使わず、ブックマークから開いて確かめる | 公式ブックマーク |

手がかりを取り逃しても進める(その場合は「先輩に相談する」が選べて、安全だが業務が遅れる)。
引っかかったときは「すぐ報告する」を選ぶと、被害が半分で済む。

## 構成

ビルドなし。`main` に push すると、GitHub Actions(`.github/workflows/pages.yml`)がそのまま GitHub Pages に配信する。

```
index.html          画面の骨組み
style.css           見た目(HUD・判断シーン・報告書・カード)
src/main.js         起動と画面の切り替え、ゲームのループ
src/game.js         ステージの中身: 物理・当たり判定・敵・仕掛け・描画(手触りは PH で調整)
src/ui.js           文字を出す画面(HTML で描く)。会話・判断シーン・手帳・初めての説明・ムービーの字幕
src/movie.js        オープニングムービー(場面ごとの長さ・字幕・描き方)
src/art.js          ドット絵(32×32 ドット)。形と陰影をコードで描き、輪郭は自動で付ける
src/sprites.js      ドット絵を画像にする。画面は 640×360 で描く(計算は 320×180 の単位)
src/input.js        キーボード・画面のボタン・ゲームパッド
src/audio.js        効果音(Web Audio で、その場で作る)
data/stage1.js      月曜のステージの地図(文字の地図)。左端の30マスは練習区間
data/story.js       台本(会話・ガードの説明)・手がかりの中身・評価と部長のひとこと
data/scenes.js      判断シーン(文面・選択肢・結果・決め手)
data/cards.js       解説カード、障害報告書・始末書の原因と再発防止策、タイトルのひとこと
scripts/check-art.mjs  ドット絵と地図の形を確かめる
art-preview.html    ドット絵を一覧で見る(確認用)
sw.js・manifest.webmanifest  PWA(オフラインでも遊べる)
icons/              アプリのアイコン(scripts/make-icons.cjs で書き出す)
```

手元で動かす: `python3 -m http.server` などでこのフォルダを配信して、ブラウザで開く(ES モジュールを使うので、ファイルを直接開くだけでは動かない)。

### ドット絵を描き足すとき

`src/art.js` に、1マス = 32×32 ドットで描く(四角・丸・線と陰影をコードで描き、最後に `outline()` で輪郭を付ける)。
色は `C` にまとめてある。描いたら `node scripts/check-art.mjs` で形を確かめ、`art-preview.html` で見た目を確かめる。

### アイコンを描き直すとき

`scripts/make-icons.cjs` の `draw()` に 32×32 ドットで描いてあり、`node scripts/make-icons.cjs` で
`icons/` に各サイズの PNG を書き出す(拡大は整数倍・ぼかしなし)。Playwright が入っている環境で動かす。

### 手口や判断シーンを足すとき

`data/scenes.js` に場面を足し、`data/stage1.js` の地図に `T` を置いて、`data/story.js` の `scenes`(順番)と `clocks`(時刻)に名前を足す。
メールの文面で `{{ }}` で囲んだところは本当に怪しいところ(印を付けると「見抜いた」)、`[[ ]]` で囲んだところは問題ない引っかけ(印を付けると「疑いすぎ」)。
引っかけは、本物と一致するものやあいさつに限る(口実や話題そのものは、怪しいと感じて当然なので引っかけにしない)。`{name}` は主人公の名前に置き換わる。
カードは `data/cards.js`。ファイルを足したり名前を変えたりしたら、`sw.js` の `FILES` と `VERSION` も直す。

## 内容について

- 社名・人名・ドメインはすべて架空。ドメインは例示用の `.example` を使っている
- 攻撃のやり方は扱わず、「どう見抜くか・どう防ぐか・やってしまったらどうするか」だけを描く
- 解説カードの出典は、資料名だけを書いてある。**リンクと確認日は、公開前に出典を開いて `data/cards.js` に追記する**
- カードに数字(件数や割合)は書いていない。書くときは、出典で確かめたものだけにする
